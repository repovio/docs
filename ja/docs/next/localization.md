Repovio
Web インターフェイスは英語で出荷されます (`en`)、ドイツ語 (`de`)、スペイン語 (`es`)、フランス語 (`fr`)、イタリア語 (`it`)、オランダ語 (`nl`)、ポーランド語 (`pl`)、ポルトガル語 (`pt`）。アプリケーション ヘッダーの言語メニューは、サインインしているすべてのユーザーが利用できます。言語を選択すると、設定が保存されます。
`repovio-locale` ブラウザの Cookie を保存し、今後の訪問時に適用します。

英語が決定的なデフォルトおよびフォールバックです。ブラウザの設定または保存された Cookie がサポートされているロケールを識別しない場合、 Repovio 英語をレンダリングします。日付、時刻、数値の書式設定には、選択したロケールが使用されます。

<a id="adding-or-updating-a-locale"></a>

## ロケールの追加または更新

1. 追加または更新 `apps/web/i18n/locales/<locale>.json` を使用して `en.json` 完全なキーリファレンスとして。
2. ロケールコード、ファイル名、ネイティブ表示名を `apps/web/nuxt.config.ts`。
3. すべてのメッセージキーが存在するようにします。 `en.json`;
   Web テスト スイートは、出荷されたロケールごとにこのパリティをチェックします。
4. ユーザーに表示される新しいインターフェイス文字列ごとに英語とドイツ語のメッセージを追加し、出荷されたすべてのロケールに対応する翻訳を追加します。
5. 走る `pnpm --filter @repovio/web test`、
   `pnpm --filter @repovio/web typecheck`、および影響を受ける Playwright テスト。

プロバイダー名、リポジトリ名、ワークフロー名、およびその他のプロバイダーが提供するデータは、変更されないため変更されません。 Repovio インターフェースのコピー。
