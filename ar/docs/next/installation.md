Repovio هي لوحة معلومات حالة سير العمل للقراءة فقط. فهو يتيح للمستخدمين المعتمدين فحص نشاط المستودع دون إنشاء أي شيء أو
إعادة تشغيله أو الموافقة عليه أو حذفه في GitHub أو GitLab أو Forgejo أو Gitea.

<a id="before-you-begin"></a>

## قبل أن تبدأ

أنت بحاجة إلى عنوان URL الخاص بتثبيت Repovio وحساب OIDC محلي أو تم تكوينه. يكمل المسؤول الأول عملية الإعداد لمرة واحدة؛
يتم توفير مستخدمين محليين إضافيين من خلال واجهة برمجة التطبيقات المحمية، أو يقوم المستخدمون بتسجيل الدخول من خلال OIDC
الذي تم تكوينه. يعتمد الوصول إلى بيانات الموفر على دورك وعضويات المستودع؛ لا يؤدي تسجيل الدخول إلى كشف كل المستودعات
التي تم تكوينها تلقائيًا.

يستخدم Repovio ثلاثة أدوار تطبيقية:

- **العارض** يمكنه فحص المستودعات المخصصة بشكل صريح، وسير العمل، والمشكلات، وطلبات السحب.
- **المدير** لديه حق الوصول للقراءة ويمكنه فحص التنبيهات الأمنية للمستودعات التي تكون فيها العضوية**مديرًا** أيضًا. تتم
  إدارة قنوات الإشعارات والاشتراكات والاختبارات والسجل عالميًا بواسطة مسؤولي النظام.
- **مسؤول النظام** يمكنه الوصول إلى كل مستودع وإدارة حسابات الموفرين والمستودعات والعضويات والمستخدمين والرموز المميزة
  MCP والإعدادات الافتراضية للتطبيق.

لا تمنح أدوار التطبيق أبدًا حق الوصول للكتابة على GitHub أو GitLab أو Forgejo أو Gitea. إذا قام أحد الإجراءات بتغيير
حالة الموفر، فسيقوم Repovio بفتح واجهة الموفر بدلاً من تنفيذ الإجراء.

<a id="recommended-first-session"></a>

## الجلسة الأولى الموصى بها

1. [تسجيل الدخول](/docs/next/sign-in)، تعلم [ملاحة](/docs/next/navigation)، وجرب [يبحث](/docs/next/search).
2. قم بمراجعة [لوحة المعلومات](/docs/next/guide-dashboard) و[جميع عمليات التشغيل](/docs/next/workflow-runs)
   و[يحتاج إلى اهتمام](/docs/next/needs-attention) و[في انتظار الموافقة](/docs/next/awaiting-approval).
3. افحص [مشاكل](/docs/next/guide-issues) و[طلبات السحب](/docs/next/guide-pull-requests).
4. افتح [المستودعات](/docs/next/repositories) لفهم البيانات التي يمكنك رؤيتها.
5. يقوم المسؤولون بتكوين [قنوات الإخطار](/docs/next/notifications) و[اشتراكات الحدث](/docs/next/notification-rules).

يجب على مسؤولي النظام بعد ذلك متابعة [الإدارة والإعدادات](/docs/next/provider-accounts). يتم ربط النشر وتسجيل الموفر
وإعداد خطاف الويب والنسخ الاحتياطي والاسترداد من صفحات الكتيب المقابلة.

<a id="when-a-page-is-empty-or-unavailable"></a>

## عندما تكون الصفحة فارغة أو غير متاحة

يمكن أن تعني الصفحة الفارغة أنه لم تتم مزامنة أي بيانات موفر متطابقة، أو أن المرشحات تستبعد جميع النتائج، أو أن حسابك لا
يحتوي على عضوية في المستودع. امسح عوامل التصفية النشطة وتحقق من اختيار المستودع أولاً. تعني رسالة خطأ التحميل أنه لا
يمكن استرداد البيانات المطلوبة؛ أعد محاولة إجراء الصفحة واطلب من مسؤول التثبيت فحص واجهة برمجة التطبيقات (API) ومهام
المزامنة إذا استمر الخطأ.
